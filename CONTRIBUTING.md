# Contributing

Create an issue for substantial changes, fork the repository, and submit a focused pull request. Use Python 3.11+, add tests for behavior changes, and run:

```bash
python -m pip install -e '.[test]'
python -m pytest
python -m pip check
```

Use synthetic device data and reserved documentation addresses. Never submit credentials, live configurations, real hostnames, customer locations, inventory databases, known-hosts files, or operational exports. Configuration-write changes must preserve explicit opt-in, exact approvals, verification, rollback, and the read-only MCP boundary.

By contributing, you agree that your contribution is licensed under Apache-2.0.
